AIvidea Studio

Private publishing tool for the owner's own YouTube channels.

What it is

AIvidea Studio is a desktop tool run by one person on their own computer. It edits short videos and publishes them to YouTube channels that the same person owns and manages. It is not offered to other users and has no public sign-up.

How it uses YouTube API Services

  • Upload: uploads finished Shorts to the owner's channels with videos.insert, sets title, description, tags and a scheduled publish time, and sets a custom thumbnail with thumbnails.set.
  • Statistics: reads view, like and comment counts of the owner's own videos and the subscriber count of the owner's own channels (videos.list, channels.list) to show them on a private, local dashboard.

The tool does not read, store or process data of any other YouTube user, and it does not like, comment, subscribe or otherwise interact with videos.

Authorization

Each channel is connected once through Google OAuth by the channel owner. Access tokens are stored only on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.
